Reactions Plugin Guide

This guide is for MyBB admins and theme developers who want to customize how the Reactions plugin looks on their forum. It covers every CSS class, template variable, and rendered HTML structure so you can tailor the plugin to match any custom theme.

Who is this for?

  • Forum admins running custom or third-party MyBB themes
  • Theme developers building themes that integrate with Reactions
  • Anyone who wants to override or extend the plugin's default styles

Installation & Setup

Setup Steps

  1. Upload the inc/plugins/Reactions/ folder to your MyBB installation.
  2. Activate the plugin from Admin CP → Configuration → Plugins.
  3. The plugin automatically applies template edits to postbit, postbit_classic, and showthread.
  4. The CSS file is automatically included via reactions.php hook on showthread pages.

Customizing Styles

The plugin's CSS is located at inc/plugins/Reactions/Assets/reactions.css. You can override any styles by adding your own CSS to your theme's stylesheet after the plugin's styles are loaded.

Template Injections

The plugin modifies core MyBB templates during activation. Understanding these injection points helps you control where plugin content appears.

Template Injection Point Variable Inserted
postbit After signature {$post['reactions_bar']}
postbit After button management area {$post['reaction_button']}
postbit After user details {$post['author_reactions']}
postbit_classic Same as postbit {$post['reactions_bar']}
{$post['reaction_button']}
{$post['author_reactions']}
member_profile After {$profilefields} {$reactions_profile_stats}
usercp_options End of form Notification preferences

If your theme uses different template names

Some custom themes rename these templates. If the plugin's elements don't appear, check that your theme's postbit template contains the standard MyBB button variables. You may need to manually add {$post['reactions_bar']} and {$post['reaction_button']} to your custom templates.

</div>

Admin CP: Recount & Rebuild

Maintenance tools to rebuild reaction data and fix inconsistencies. Located at Admin CP → Tools & Maintenance → Recount & Rebuild → Reactions.

Recount User Reactions

Recalculates all user reaction scores based on actual reaction_content table data.

  • Updates reaction_score for all users
  • Updates reaction_given_score for all users
  • Fixes inconsistencies from manual database edits
  • Processes in batches (configurable per_page)

Recount Post Reactions

Rebuilds post reaction caches and score data.

  • Updates post reaction_score column
  • Rebuilds JSON reactions cache
  • Rebuilds JSON reaction_users cache
  • Processes in batches (configurable per_page)

Convert Reactions to Reputation

Creates reputation entries from existing reactions.

  • Converts reaction scores to reputation points
  • Respects reputation system settings
  • Optional: include negative reactions
  • Skips existing reputation entries

Initialize Reaction Removed Alert

Sets up default user preferences for reaction removal alerts.

  • Sets reaction_removed alert default to disabled
  • Does not override existing user preferences
  • Used after enabling MyAlerts integration

Batch Processing

All recount operations use configurable batch processing to prevent timeout on large forums. Default batch size is 100 items per page.

MyAlerts Integration

The Reactions plugin integrates with the MyAlerts plugin to provide notification functionality for users.

Alert Types

Alert Type Default Description
reaction Enabled Sent when someone reacts to your post
reaction_removed Disabled Sent when someone removes a reaction from your post

Alert Formatter

Alert messages include:

  • Reaction image/icon inline with message
  • Username of user who reacted
  • Link to the reacted post
  • Reaction type name

User Preferences

Users can configure MyAlerts settings at User CP → Alerts → Settings:

  • Checkbox to enable/disable reaction alerts
  • Checkbox to enable/disable reaction_removed alerts
  • Preferences persist across sessions

Requirements

Prerequisites

  • MyAlerts plugin must be installed and active
  • MyAlerts version 2.0.4 or higher recommended
  • Enable reactions_integrate_myalerts in settings

Automatic Alert Creation

Alerts are automatically generated when:

  • A user gives a reaction to a post
  • The post author has reaction alerts enabled
  • The reaction is not from the post author themselves

reactions_enabled Yes/No 1 Globally enable/disable reactions
reactions_min_posts Numeric 0 Minimum posts required to react
reactions_min_reputation Numeric 0 Minimum reputation required
reactions_self_react Yes/No 0 Allow users to react to own posts
reactions_closed_threads Yes/No 0 Allow reactions in closed threads
reactions_edit_time_limit Numeric 0 Minutes to edit/remove (0=unlimited)
reactions_flood_time Numeric 0 Seconds between reactions
reactions_excluded_forums Forum Select None Forums where reactions are disabled

Display Settings

Setting Type Default Description
reactions_display_postbit Yes/No 1 Show scores in postbit
reactions_display_profile Yes/No 1 Show stats in profile
reactions_user_notification_prefs Yes/No 1 Allow users to configure notifications

Permission Settings

Setting Type Default Description
reactions_view_groups Group Select -1 (all) Groups that can view reactions
reactions_use_groups_list Group Select 1,7 Groups NOT allowed to give reactions
reactions_receive_groups Group Select 1,7 Groups NOT allowed to receive reactions
reactions_remove_groups_list Group Select 2,3,4,6 Groups allowed to remove reactions
reactions_super_groups Group Select 3,4,6 Super user groups (bypass all restrictions)

Integration Settings

Setting Type Default Description
reactions_integrate_myalerts Yes/No 0 Send MyAlerts notifications
reactions_integrate_reputation Yes/No 0 Add reaction scores to reputation
reactions_reputation_allow_negative Yes/No 1 Allow negative reactions in reputation
reactions_gift_reputation Yes/No 1 Convert gifted points to reputation

Forum Settings

Setting Type Default Description
reactions_excluded_forums Forum Select (empty) Forums where reactions are disabled
